# Static Website Deployment Using GitHub Pages

Demonstration of static website hosting and Git-based deployment workflow
using GitHub Pages, covering branching, pull requests, and version control practices.

---

## What This Project Demonstrates

- Initializing a Git repository and pushing to GitHub
- Creating feature branches and making changes independently
- Opening and merging Pull Requests
- Deploying a static website using GitHub Pages
- Managing version control with a clean commit history

---

## Tech Stack

HTML | CSS | JavaScript | Git | GitHub Pages
